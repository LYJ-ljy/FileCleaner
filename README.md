# 文件智理助手

智能文件整理 + 重复文件清理工具，基于 Python + Tkinter 构建的桌面 GUI 应用。

## 功能概览

### 📂 智能文件整理
选中目标文件夹，自动根据文件扩展名将散乱的文件分类到对应子文件夹中（图片、文档、视频、音乐、代码等），告别杂乱无章的目录。

### 🔍 重复文件清理
基于 **MD5 哈希** 扫描文件夹内所有文件，识别内容完全相同的重复文件组，支持可视化勾选删除，每组自动保留至少一个原始文件。

## 技术亮点

| 亮点 | 说明 |
|------|------|
| **MD5 快速去重** | 小文件全量哈希，大文件（>2MB）智能采样首尾各 1MB 计算哈希，兼顾准确性与扫描速度 |
| **JSON 规则配置** | 分类规则全部定义在 `rules.json` 中，可自由增删分类、修改扩展名映射，热加载无需改代码 |
| **多线程非阻塞** | 文件扫描和整理操作运行在独立线程中，UI 不会被卡死，进度条实时反馈 |
| **安全删除** | 优先使用 `send2trash` 移至回收站（可恢复），未安装时自动回退到直接删除并给出提示 |
| **单文件打包** | 支持 PyInstaller `--onefile` 打包为独立 `.exe`，分发无需安装 Python 环境 |

## 快速开始

### 方式一：直接运行 Python 脚本

**环境要求：** Python 3.8+

```bash
# 1. 安装可选依赖（增强功能）
pip install send2trash      # 安全删除（移至回收站），推荐安装
pip install python-magic    # 更精确的文件类型检测（可选）
pip install Pillow          # 图片预览支持（可选）

# 2. 运行
python cleaner.py
```

### 方式二：使用打包好的 EXE（无需 Python 环境）

1. 下载 `cleaner.exe`
2. 将 `rules.json` 放在 `.exe` 同一目录下（可选，未找到时使用内置默认规则）
3. 双击运行

#### 自行打包

```bash
pip install pyinstaller
pyinstaller --onefile --windowed cleaner.py
# 生成的 exe 在 dist/ 目录下
# 将 dist/cleaner.exe 与 rules.json 放在同一目录即可使用
```

## 使用说明

### 文件整理
1. 点击 **浏览** 选择要整理的目标文件夹
2. 点击 **开始整理文件**
3. 程序按 `rules.json` 中定义的规则，将文件按扩展名移动到对应分类子文件夹中
4. 已有的分类文件夹不会被二次移动

### 重复文件清理
1. 点击 **浏览** 选择要扫描的目标文件夹
2. 点击 **查找并清理重复文件**
3. 扫描完成后弹出窗口，展示所有重复文件组
4. 勾选要删除的副本（每组第一个文件自动保留，不可勾选）
5. 点击 **确认删除所选文件** 完成清理

## 自定义分类规则

编辑 `rules.json`，按以下格式添加或修改分类：

```json
{
    "图片": [".jpg", ".jpeg", ".png", ".gif", ".bmp", ".ico", ".svg", ".webp"],
    "文档": [".pdf", ".doc", ".docx", ".txt", ".md", ".xls", ".xlsx"],
    "压缩包": [".zip", ".rar", ".7z", ".tar", ".gz"],
    "视频": [".mp4", ".mkv", ".flv", ".avi", ".mov"],
    "音乐": [".mp3", ".wav", ".flac", ".aac"],
    "代码": [".py", ".js", ".html", ".css", ".cpp", ".java", ".go"],
    "其他": []
}
```

- 键名即为子文件夹名
- `"其他"` 分类用于收纳未匹配到任何规则的文件，**必须保留**
- 扩展名统一用小写，程序匹配时会自动转小写比较
- 修改后重新启动程序即可生效
